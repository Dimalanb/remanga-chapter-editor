# ReManga: Отметить несколько глав прочитанными (remanga-chapter-editor)

Удобный юзерскрипт (.js) для массового управления прочитанными главами на сайте **Remanga.org**. 

Данный скрипт позволяет быстро **отметить сразу несколько глав прочитанными** (включая выбор диапазона или вообще все главы произведения), а также массово снять отметку «прочитано».

### Почему это нужно?
На официальном сайте ReManga нет встроенной функции для массового выделения. Нажимать на «глазик» каждой отдельной главы вручную — это долго и неудобно. Скрипт незаменим, если вы читаете мангу на сторонних ресурсах, а на Реманге только отмечаете прогресс и ведете списки.
