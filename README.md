# remanga-chapter-editor
ReManga — Управление прочитанными главами

Простой .js для работы с главами на сайте Remanga. Данный скрипт позволяет отметить сразу несколько глав прочитанными, в том числе все, а также снять отметку прочитано с нескольких глав или всех. Данный скрипт был сделан, так как глазик нажимать на каждую отдельную главу, это издевательство. Особенно если читаешь на сторонних ресурсах, а сервис реманга используешь для отслеживания прочитанных произведений.
